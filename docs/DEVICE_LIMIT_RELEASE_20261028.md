# NodeEndpoint 1.0.10 设备限制修复联动

配套版本：Xboard `v2026.10.28.1`、NodeEndpoint `1.0.10`、xboard-node `v1.13-orphan.7`、独立 Node 工具包 `1.0.9`。

NodeEndpoint 1.0.9 的机器管理命令和工具发行锁固定在 Node v6。只发布新 Node 不会改变这些命令，因此本版同步更新域名／IP 两种新装命令、原生插件包中的工具以及独立工具包。安装器采用同 tag 的正式 Release 资产，`--version` 固定为 v7。已有机器按[升级教程](UPGRADE.zh-CN.md)单独升级，不使用新装命令替换绑定。

面板和 Node 的配套修复包含：完整在线快照（包括空快照）清理已离线 IP、按用户和 IP 原子占用跨节点名额、拒绝新 IP 绕过已连接 IP 的限额、保留从不限额迁移过来的旧连接名额，以及两内核在失去面板续约后关闭仍活跃的限额用户连接。在线数表示去重的来源 IP，不代表可识别的物理设备数量。同一公网 IP 下多设备共用一项，IPv4 与 IPv6 可能分别占项。

本轮隔离 VM 的观测为：正常关闭约1秒、客户端网络黑洞约36秒、节点暂停后约57秒；最终候选中，面板网络黑洞后53.935秒关闭连接，恢复后10.199秒通过稳定验收。这些是特定 VLESS/TCP、REST 和受控 loopback 场景的实测，包含轮询与调度影响，不是所有网络条件下的时间承诺。网络中断通过 TCP 保活和租约判定；空闲但仍连通的连接不因没有业务流量而直接清除。

配套面板的公开[验收记录](https://github.com/ksr-v/Xboard-Custom-Source/blob/v2026.10.28.1/docs/installation/release-2026.10.28.1-validation.zh-CN.md)区分最终候选与早期 B7：最终 Node 全 internal race 489 项，以及9个真实场景31条断言；B7 的20场景69条断言保留为历史。面板 HTTP 56、Admin SQL／WS 回调14、UI 构建7、补丁器20、旧全插件审计10项分别记录。旧插件兼容审计对象是 1.0.9，不能作为 1.0.10 完整组件套件的重跑证据。

本插件本次只改变版本元数据和新装命令；随包工具更新发行锁与文档。Root 引导仍固定 `root-installer-v1.0.9 / tools 1.0.6`，既有入口、CA、托管口令、机器 Token 和数据库保持现有配置。旧 ZIP、tag、Release 资产不覆盖。

本轮未重跑真实 WS 网络、浏览器、原生 ARM64 业务、公网 NAT／IPv6 和长期压力测试。NodeEndpoint 的命令生成、工具单元和发布包验证结果在[本次插件验证记录](RELEASE_VALIDATION_DEVICE_LIMIT_20261028.md)中单列，不扩大为上述未测范围。
