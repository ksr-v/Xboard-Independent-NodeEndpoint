# 2026-10-25 发行验证

本次配套发布独立 Xboard `v2026.10.25.1`、NodeEndpoint `1.0.8`、独立 Node `v1.13-orphan.5`，独立迁移工具为 `1.0.7`。Root 入口继续使用 `root-installer-v1.0.9 / tools 1.0.6`；无需重建已有 CA。

## 验证结果

- 正式发行 Node 的 40 项独立模式及 40 项机器模式联测全部通过，包含实际 TCP 请求、限速和配置载荷核对。两个内核分别验证 1/8 Mbps、同用户共享桶、不同用户隔离、同一连接限速启停、路由顺序、阻断、精确域名和出口变化。
- 四个正式程序的 SHA、ELF 架构和版本通过。AMD64 在授权 Linux VM 原生执行；ARM64 通过已有可信 QEMU 做版本 smoke，不等同于原生 ARM64 业务验收。
- 最终源码的四包 Linux `-race` 通过。后端 13 个限速/路由场景与 13 个内置插件升级/状态保留场景通过；NodeEndpoint 原生组件 36 项及 Root 命令 9 项通过。
- v5 安装器对域名和私有 CA 两种方式校验固定程序摘要，并明确拒绝非 v5。安装器 21 项通过、1 项环境跳过；替换/恢复 26 项通过、2 项环境跳过；资产验证与维护补丁工具各 5 项通过。
- 测试 Node/Go 进程及本轮容器已退出，测试端口释放；原面板返回 HTTP 200。此次正式程序回归未读取 Root 私有诊断日志，也未替换生产服务。

[正式程序安全记录](verification/node-v5-release-20261025.json)保留完整测量及清理结果；[原始修复报告](RATE_ROUTE_FIX_REPORT.md)保留修复过程、历史失败、最终源码专项检查与测量边界。
