      新增 Node 对接命令

      默认准备独立 Node 最新正式版本并核对摘要，准备成功后固定该次版本用于安装。Token 在 SSH 终端交互输入；已有实例请使用下方迁移流程。

      认证 WSS 测试会注册该身份的连接并清理设备状态。已运行的节点应先备份并停服迁移。

      在已校验摘要的当前插件 ZIP 的 NodeEndpoint/ 目录执行，需要保留完整 tools/。

      迁移已有节点

      1. 在 Node 服务器通过 SSH 执行 python3 tools/node/node_endpoint.py inspect --config 指定实例配置，确认实例身份、原面板地址和部署方式。
      2. 从可信渠道复制公共 CA，核对独立 SHA-256 指纹。Root 工具备份证书和独立入口配置。
      3. 执行工具的 migrate 模式，明确提供实例 ID、原 URL、配置、凭据、元数据和 systemd 服务。未知布局会拒绝修改。
      4. 预检 REST、WSS 后输入指定迁移确认。仅更改目标实例 URL，失败时恢复原配置和服务。
      5. 逐实例确认在线、流量、绑定与 WSS。FlowScope 采集器单独确认，其 panel_url 不会随 Node 改变。

      不要对生产多实例运行上游安装器的重装动作。更换同 CA 的服务器证书无需重新导入 CA；更换 CA 先部署双信任，验证所有 Node 后再移除旧 CA。
